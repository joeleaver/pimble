Download Pimble

The desktop app keeps your stores on your own disk and runs without a network or an account. Each package carries two programs: pimble, the app, and pimble-mcp, the MCP server for LLM clients.

Linux: Ubuntu and DebianFor this computer
Puts Pimble in your app launcher and pimble and pimble-mcp on your PATH. Install it with sudo apt install ./pimble_*.deb; installing a newer one upgrades it. Needs Ubuntu 24.04, Debian 13 or newer.

Linux: any distributionFor this computer
The same two programs in a tar.gz. Extract it and run ./pimble --install to put Pimble in your home folder, your app menu and your PATH, where it keeps itself up to date; or just run ./pimble from where it is. 64-bit x86, glibc 2.38 or newer (Ubuntu 24.04, Fedora 39, Debian 13 and later).

WindowsFor this computer
An installer that sets Pimble up for your account alone, with pimble-mcp.exe beside it; no administrator rights needed. 64-bit Windows.
A zip holding pimble.exe and pimble-mcp.exe, with no installer. Unzip it anywhere and run pimble.exe. 64-bit Windows.
Or the portable zip : unzip it anywhere and run pimble.exe, nothing installed.

    Connect an LLM

    Point your MCP client at pimble-mcp from the package. For Claude Code:

    claude mcp add pimble -- /path/to/pimble-mcp

    It joins the Pimble app if it is running, or opens your stores itself if not.
