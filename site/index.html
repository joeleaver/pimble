One tree of notes, however many devices you open it from.

Pimble keeps everything you write as nodes in a tree, inside a folder on your own disk. Open it offline on the desktop, open the same tree in a browser, hand a copy to someone else — every edit merges back together, because the document underneath is built to be edited from more than one place at once.

  • Nodes in a tree

    A store is a folder of nodes, each one a page of formatted text, arranged however you like: a manuscript's chapters, a project's sources, a household's paperwork. There's no separate database to keep in sync with the files — the folder is the store.

  • Merges, not conflicts

    Both a node's content and the tree's structure are CRDTs. Two people can edit the same node at the same time, on machines that have never spoken to each other, and reconcile later without either edit being thrown away.

  • Mounts

    Any subtree of any store can appear inside any other store's tree. A shared reference library can sit inside three different projects at once, edited from any of them, without ever being copied.

  • Search that understands what you meant

    Every store keeps its own local index: keyword search over titles and text, and semantic search that finds a passage by what it says rather than the exact words it uses.

  • Brought in from Scrivener

    The importer reads a Scrivener project's binder, its labels and its formatting, and rebuilds it as a Pimble tree — colours and tags included.
