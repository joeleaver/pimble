Plugins

Plugins show a node's notes in new ways: a board of cards, a checklist, a line of time. Pimble signs every one and checks it before it is installed. You install them in the app, under Settings > Plugins, and they keep themselves up to date.

Install in Pimble opens the desktop app at that plugin, ready to install; it needs Pimble on this computer, so download it first if you have not. Open in the web app does the same in the browser.
